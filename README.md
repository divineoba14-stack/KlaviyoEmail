📬 Email Development Repository

A collection of responsive, production-ready HTML email templates built using pure inline CSS for maximum cross-client compatibility. 

Projects Included

1. Welcome Email — Aura Leather
* Goal: Onboard new customers with a premium brand experience.
* Key Features: Hero image integration, brand storytelling layout, and clear primary CTA.

2. Promotional Email — Glowsystem
* Goal: Drive seasonal sales and highlight key product collections.
* Key Features: Multi-column product grid, dynamic discount banners, and urgent countdown styling.

3. Account Upgrade Email
* Goal: Convert free tier users to premium subscriptions.
* Key Features: Clean benefit comparison layout, trust-building social proof, and high-contrast CTA buttons.

Build Specs & Testing

* Languages: Semantic HTML5, Pure Inline CSS
* Standards: Table-based layouts optimized for Outlook, Gmail, and Apple Mail
* Testing: Verified across mobile, desktop, and dark mode clients.

How to Run Locally

1. Clone this repository:
   git clone https://github.com

2. Open any index.html file in your browser to inspect the layout.
